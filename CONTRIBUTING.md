# Contributing to MCQ Prep Portal

Thank you for contributing to the competitive exam portal!

## Question Bank Contributions
- Questions must be properly categorized into their respective subject and unit numbers.
- Each question must include exactly 4 distinct options and a valid 0-indexed correct answer pointer.
- Questions must be fact-checked against official technical curricula.

## Pull Request Guidelines
- Verify build with `npm run build` prior to submission.
- Ensure Zustand state updates maintain immutability.
