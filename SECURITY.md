# Security Policy

**MCQ Prep App** is a client-side competitive exam preparation and testing portal.

---

## 🔒 Security Practices

1. **Client-Side Simulation:** Test questions, timers, and scoring algorithms run in the user's browser.
2. **Zero Tracking:** No user surveillance or invasive test tracking cookies.
3. **Vulnerability Disclosure:** Report security concerns to `tanmaynileshshinde@gmail.com`.
